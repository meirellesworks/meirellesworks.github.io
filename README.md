# meirellesworks.com

Site do MeirellesWorks: serviços de engenharia, projetos pessoais, loja e contato.

Página estática em um único `index.html`, publicada pelo GitHub Pages com domínio próprio (`CNAME`).

- Links das redes, e-mail e itens da loja: bloco `CONFIG`, `PRODUCTS` e `TIERS` no fim do `index.html`.
- Logos oficiais (SVG, texto em curvas): `assets/logo/`.
